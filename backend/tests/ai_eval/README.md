# AI evaluation suite

Datasets (`datasets/*.jsonl`) are generated by `build_datasets.py` and committed; a test fails when they drift. Sizes and pass thresholds are the approved DEC-17 values in `harness.py` (`THRESHOLDS`).

```
cd backend
uv run pytest tests/ai_eval              # everything that runs in CI; writes ai_eval_results.json
uv run python -m tests.ai_eval.build_datasets   # regenerate the datasets
uv run python -m tests.ai_eval.live      # pre-release routing run against a real provider
python ../scripts/ai_eval_report.py      # results as a Markdown table
```

Results, method and limits: [docs/ai-evaluation.md](../../../docs/ai-evaluation.md).
